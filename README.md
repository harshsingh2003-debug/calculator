# React Calculator

## 📌 Project Overview

The **React Calculator** is a modern and responsive web application built using **React.js**. It is designed to perform basic arithmetic operations with a clean, intuitive, and user-friendly interface. The application demonstrates the use of **React functional components**, **React Hooks**, and **state management** to create a dynamic and interactive user experience.

The calculator provides instant results as users interact with the interface, ensuring smooth and efficient performance. It also includes input validation and error handling to prevent invalid calculations, making it both reliable and easy to use. The responsive design allows the application to work seamlessly across desktops, tablets, and mobile devices.

This project was developed to strengthen core React concepts such as component-based architecture, event handling, conditional rendering, and state management while building a practical real-world application.

---

## 🚀 Features

* Perform all basic arithmetic operations:

  * Addition (+)
  * Subtraction (-)
  * Multiplication (×)
  * Division (÷)
* Real-time calculation and instant result updates.
* Clear (C) button to reset the calculator.
* Delete (⌫) functionality to remove the last entered character.
* Handles decimal numbers accurately.
* Prevents invalid mathematical expressions.
* Displays appropriate error messages for invalid operations such as division by zero or incorrect input.
* Responsive and mobile-friendly interface.
* Clean and modern UI with smooth user interaction.
* Fast performance using React's efficient rendering.



## 💡 How It Works

1. Click the number buttons to enter values.
2. Select an arithmetic operator (+, −, ×, ÷).
3. Enter the second number.
4. Press the **=** button to calculate the result instantly.
5. Use the **C** button to clear all inputs.
6. Use the **⌫** button to delete the last entered digit.

The application stores user input using React's `useState` Hook. Every button click updates the state, and the calculator dynamically renders the current expression and result without reloading the page.
